# 2026-08-16

## 修复前端空白页面
- 定位根因：`handler/web_ui.go` 中 `loadFiles()` 的 JS 出现语法错误：`const act=it.is_dir` 声明未完成，下一行直接出现 `const openPath=...`，随后再次 `const act=it.is_dir ? ... : ...`。整段 `<script>` 无法执行，导致所有 `.view` 保持 `display:none`、菜单点击无反应。
- 修复：移除重复声明，合并为单一 `const act=it.is_dir ? ... : ...`；并新增 `showError()`、`window.onerror` 及所有视图加载函数的 try/catch，避免 API 失败时页面空白。
- 验证：`node --check /tmp/web_ui.js` 通过；浏览器预览 `http://127.0.0.1:8080/` 可正常显示概览卡片与菜单切换。

## 修复运行时死锁
- `repository/userstore.go`：`Upsert`/`Delete` 持有写锁时调用 `save()`（内部又获取读锁），导致 RWMutex 自死锁。新增 `saveLocked()`（调用方持锁），`Upsert`/`Delete` 改用它。
- `handler/web.go`：`StartWeb` 在 goroutine 中丢弃 `r.Run` 错误，Web 绑定失败时 main 仍 `select{}` 空等 → runtime deadlock。改为通过 channel 在 1.5s 内捕获绑定错误并返回，main 据此 `log.Fatalf` 干净退出。

## 后台界面重构
- `handler/web_ui.go` 重写为左侧菜单栏 SPA：概览 / 用户管理 / 文件管理 / 基础设置 / 系统配置，响应式适配移动端。
