# 2026-08-16

## 修复前端空白页面
- 定位根因：`handler/web_ui.go` 中 `loadFiles()` 的 JS 出现语法错误：`const act=it.is_dir` 声明未完成，下一行直接出现 `const openPath=...`，随后再次 `const act=it.is_dir ? ... : ...`。整段 `<script>` 无法执行，导致所有 `.view` 保持 `display:none`、菜单点击无反应。
- 修复：移除重复声明，合并为单一 `const act=it.is_dir ? ... : ...`；并新增 `showError()`、`window.onerror` 及所有视图加载函数的 try/catch，避免 API 失败时页面空白。
- 验证：`node --check /tmp/web_ui.js` 通过；浏览器预览 `http://127.0.0.1:8080/` 可正常显示概览卡片与菜单切换。

## 修复运行时死锁
- `repository/userstore.go`：`Upsert`/`Delete` 持有写锁时调用 `save()`（内部又获取读锁），导致 RWMutex 自死锁。新增 `saveLocked()`（调用方持锁），`Upsert`/`Delete` 改用它。
- `handler/web.go`：`StartWeb` 在 goroutine 中丢弃 `r.Run` 错误，Web 绑定失败时 main 仍 `select{}` 空等 → runtime deadlock。改为通过 channel 在 1.5s 内捕获绑定错误并返回，main 据此 `log.Fatalf` 干净退出。

## 配置保存即时生效（热重载）改造
- 用户反馈：在 Web 页面改端口没生效。根因：旧二进制未包含热重载代码，且**Web 端口改动本就需要重启进程**（Gin 绑定后不能换端口）。
- 后端：`config/config.go` 修复 `Save()` 锁降级竞态（改为写锁内 `saveLocked()`）；新增 `ftpReloader` 回调 + `RegisterFTPReloader`；`UpdateFromMap` 检测 FTP 字段变更后触发热重载。
- `service/ftpserver.go`：`StartFTP` 改为 `ftpController`，注册 `cfg.RegisterFTPReloader`，配置变更时 `Shutdown()`+重建 server（goftp/server 支持 `Shutdown`，优雅断开新连接、保留旧会话）。
- `handler/web.go`：`updateConfigHandler` 返回 `web_port_changed`，提示文案区分"FTP 已热重载"与"Web 端口需重启"。
- `handler/web_ui.go`：保存成功后重新 `loadBasic()`+`loadOverview()` 刷新界面（不刷新页面），Web 端口变更时 toast 提示重启。
- 验证：PUT /api/config 改 `ftp_port` 2121→2122，**进程 PID 不变**，FTP 监听切到 2122，接口返回"FTP 服务已热重载，无需重启"。已恢复 2121。
- 注意：当前运行服务 Web 监听 9091（用户在页面把 web_port 从 9090 改成了 9091，已落盘 config.json）。
