## 前端界面重构（深空控制台风）
- 用户要求「构建好看的前端页面，可以使用框架」。
- 决策：项目是单二进制 Go 程序（前端内联在 handler/*.go），引入 React/Vite 会破坏分发。改用 **Tailwind CDN 原型 → 最终纯内联 CSS**（因内网服务器可能无外网，CDN 不可靠）。设计语言「深空控制台风」：玻璃拟态 + 青色(#22d3ee)辉光 + JetBrains Mono 等宽字体(含系统字体 fallback) + 入场动画 + 渐变光晕背景。
- 重写文件：`handler/web_ui.go`(DashboardHTML 控制台 SPA)、`handler/web_auth_pages.go`(LoginHTML/RegisterHTML 登录注册页，统一风格)。
- 所有功能保持不变：概览/用户/文件/基础设置/系统 + 配置热重载刷新界面。
- 验证：`go build`+`go vet` 通过；启动后登录页/控制台 HTML 正确返回；服务 Web :9091 / FTP :2121。
- 注意：早期 Tailwind CDN 版本已废弃，最终内联 CSS 已提交。Go 原始字符串不能含反引号 → JS 模板字面量用字符串拼接。

## SQLite + RBAC 权限改造
- 用户要求将 JSON 用户存储改造为 SQLite，新增 admin/普通用户 角色分级；普通用户可上传/下载/删除/新建目录/浏览；密码 bcrypt 哈希。
- 新增 `repository/dbstore.go`（纯 Go 驱动 `modernc.org/sqlite`，无 cgo，保持单二进制）。首启种子 `admin/admin123`；自动迁移旧 `configs/users.json`（明文→bcrypt，改名 `.migrated`）；`guardLastAdmin` 防删最后管理员。
- `model.User` 移除 `Password`/`ReadOnly`，新增 `Role`(`admin`/`user`)、`PasswordHash`、`IsAdmin()`、`CanWrite()`。
- `handler/auth.go` 新增 `RequireRole("admin")` 中间件；`web.go` 将 `/api/users`、`/api/config`、`/api/system` 归入 admin 分组（普通用户访问返回 403），文件接口对全体登录用户开放；`/api/me` 返回 `is_admin`。
- FTP `ftpserver.go` 写操作由 `u.ReadOnly` 改为 `u.CanWrite()`（仅禁用账户受限，普通用户可写）。
- 前端 `web_ui.go`：导航/新增用户按钮加 `data-admin`，`/api/me` 后对非管理员隐藏管理入口并阻止跳转；用户弹窗改用角色下拉；概览页用户总数仅管理员可见。
- 删除旧 `repository/userstore.go`；`main.go` 参数 `-users` → `-db`；README 同步更新（用户/权限章节、项目结构、configs 说明）。
- 验证：go build + go vet 通过；RBAC 冒烟测试通过（admin 可管理、bob 普通用户被 403 拦截管理接口但可上传/下载/建目录/删除，最后管理员保护生效）。
